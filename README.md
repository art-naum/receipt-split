# 🧾 Розкладка чеку

Веб-застосунок для розподілу фіскального чека між кількома покупцями. Завантажуєш XML-файл чека — і по кожній позиції обираєш, хто за неї платив: одна людина, порівну на кількох, вручну сумою, за відсотками або частками.

Один HTML-файл, працює повністю в браузері — без сервера і бекенду.

## Можливості

- Завантаження фіскального чека у форматі XML — з автоматичним розпізнаванням кодування, позицій, знижок і суми оплати.
- Список покупців, з якими регулярно ділите витрати.
- Розподіл кожної позиції: одному покупцю, порівну, вручну сумою, за відсотками або частками.
- Підсумок витрат по кожному покупцю, з попередженням про нерозподілені позиції.
- Історія чеків з деталізацією по кожній позиції та загальним підсумком по всіх чеках.
- Повернення чека з історії назад у роботу для редагування розподілу.
- Збереження всіх даних у JSON-файл і завантаження його назад для продовження роботи.

## Приватність

Усі дані обробляються локально, у браузері. Нічого нікуди не надсилається. Єдиний спосіб зберегти дані між сеансами — кнопка «Зберегти файл».

## Використання

Відкрийте `index.html` у браузері.

1. Додайте покупців.
2. Завантажте XML-файл чека.
3. По кожній позиції оберіть, кому вона належить, і спосіб розподілу.
4. Перегляньте підсумок витрат.
5. «Зберегти чек в історію» — щоб зафіксувати результат.
6. «Зберегти файл» — щоб не втратити дані між сеансами.

## Технічні деталі

- Один файл `index.html` — HTML, CSS, JavaScript.
- Без збірки, npm і фреймворків.
- Єдина зовнішня залежність — шрифти Google Fonts (Fraunces, Inter, JetBrains Mono).
- Формат вхідного чека — фіскальний XML українського зразка (ФОП/ПРРО): теги `<P>` (позиції), `<D>` (знижки), `<M>` (оплата), `<E>` (податкова інформація).
