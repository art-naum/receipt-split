# 🧾 Розкладка чеку

Веб-застосунок для розподілу фіскального чека між кількома покупцями. Завантажуєш XML-файл чека — і по кожній позиції обираєш, хто за неї платив: одна людина, порівну на кількох, вручну сумою, за відсотками або частками.

Один HTML-файл, працює повністю в браузері — без сервера і бекенду.

## Можливості

- Завантаження фіскального чека у форматі XML — підтримуються обидві поширені схеми: компактний формат `<RQ><DAT><C>` (різні каси/ПРРО) і офіційна схема ДПС `<CHECK><CHECKHEAD>` (check01.xsd).
- Автоматичне розпізнавання кодування, позицій (кількість, ціна, сума), знижок, податкових груп, реквізитів продавця та способу оплати.
- Список покупців, з якими регулярно ділите витрати — ім'я автоматично починається з великої літери.
- Розподіл кожної позиції: одному покупцю, порівну, вручну сумою, за відсотками або частками (прості дроби на кшталт 1/4).
- Якщо розподіл не сходиться рівно (наприклад, через округлення на кшталт 33.33%×3), залишок можна докинути одним кліком тому покупцю, з яким востаннє працювали.
- Під кожною позицією видно кількість, ціну та суму — так само, як на самому чеку, разом зі знижкою, якщо вона є.
- Підсумок витрат по кожному покупцю з рядком «Разом», і розгортання деталізації — які саме позиції та в якій пропорції оплатив кожен.
- Розгортаний блок «Усі деталі чека»: фіскальний номер, ІД/ПН продавця, номер чека, дата й час, спосіб оплати з реквізитами картки або готівки, податкові групи з позначенням літерою.
- Історія чеків з деталізацією по кожній позиції та загальним підсумком по всіх чеках, з можливістю повернути будь-який чек з історії назад у роботу для редагування.
- Збереження всіх даних у JSON-файл і завантаження його назад для продовження роботи з того самого місця.

## Приватність

Усі дані обробляються локально, у браузері. Нічого нікуди не надсилається. Єдиний спосіб зберегти дані між сеансами — кнопка «Зберегти файл», яка з'являється, щойно є що зберігати.

## Використання

Відкрийте `index.html` у браузері.

1. Додайте покупців (Enter теж додає).
2. Завантажте XML-файл чека.
3. По кожній позиції оберіть, кому вона належить, і спосіб розподілу.
4. Перегляньте підсумок витрат — клацніть на ім'я покупця, щоб побачити деталізацію.
5. «Зберегти чек в історію» — щоб зафіксувати результат і перейти до наступного чека.
6. «Зберегти файл» — щоб не втратити дані між сеансами.

## Технічні деталі

- Один файл `index.html` — HTML, CSS, JavaScript.
- Без збірки, npm і фреймворків.
- Єдина зовнішня залежність — шрифти Google Fonts (Fraunces, Inter, JetBrains Mono).
- Формати вхідного чека:
  - `<RQ><DAT><C>` — теги `<P>` (позиції), `<D>` (знижки), `<M>` (оплата), `<E>` (податкова інформація);
  - `<CHECK><CHECKHEAD>` (check01.xsd) — `<CHECKHEAD>`, `<CHECKTOTAL>`, `<CHECKPAY>`, `<CHECKTAX>`, `<CHECKBODY>`.
